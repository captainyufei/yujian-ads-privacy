# Yujian Ads API privacy policy

Public English privacy notice for **Yujian Ads API**, operated by **Yujian Future (Shenzhen) Technology Co., Ltd**.

- Privacy policy: https://captainyufei.github.io/yujian-ads-privacy/
- Public contact: captainaigc@163.com
- Confirmed scope: analysis of the company's own advertising accounts and management of bids and budgets.

## Publishing

GitHub Pages serves the static `index.html` file from the root of the `main` branch. `.nojekyll` disables Jekyll processing. No build dependencies are required.

Update `index.html` and its last-updated date, commit, and push to `main` to publish revisions.

## Policy scope

The notice describes the intended authorized use of the integration and its security and data-handling requirements. Publishing this notice does not implement or audit the integration's backend controls. Keep the notice aligned with actual operations as the tool is developed and enabled.

This repository contains only the public policy page and publishing information.
